# MERN Expense Tracker

A full-stack expense tracking application built with:

- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication
- bcrypt
- MongoDB Aggregation

## Features

### Authentication

- User registration
- User login
- Password hashing with bcrypt
- JWT authentication
- Protected expense APIs

### Expense Management

- Create expense
- View own expenses
- Edit expense
- Delete expense
- Category selection
- Expense date

### Analytics

- Total spending
- Total transaction count
- Average expense
- Category-wise totals
- MongoDB `$group` aggregation
- Simple category bar chart

## Categories

- Food
- Travel
- Bills
- Shopping
- Other
